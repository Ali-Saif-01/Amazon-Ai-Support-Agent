# Reply Quality LLM-as-Judge Rubric

## Purpose

This evaluation compares the support replies generated by the agent against a
human-reviewed subset of 50 golden examples.

The LLM judge evaluates the generated reply independently using the same
overall 1–5 quality scale used by the human review.

## Evaluation dimensions

Each response is assessed on:

- **Relevance** — Does the reply address the customer's actual issue?
- **Groundedness** — Does the reply avoid unsupported claims and remain consistent
  with the available historical evidence?
- **Helpfulness** — Does it provide a useful next step or actionable guidance?
- **Professional tone** — Is it clear, respectful, concise, and appropriate for
  customer support?
- **Unsupported claims** — Does it introduce claims not supported by the
  customer message or available evidence?
- **Overall quality** — Holistic quality score from 1 to 5.

## Overall quality scale

### 5 — Excellent
Directly addresses the customer's issue, is grounded, useful, and professionally
written. Provides an appropriate next step without unnecessary generic language.

### 4 — Good
Clearly relevant and generally useful, with only minor omissions or generic
wording.

### 3 — Acceptable
Broadly relevant but noticeably generic, incomplete, or missing an important
detail.

### 2 — Poor
Partially relevant but misses an important aspect of the customer's issue or
provides weak guidance.

### 1 — Very poor
Irrelevant, misleading, or fails to address the customer's actual issue.

## Agreement measurement

The LLM judge was applied to the same 50 examples that received human overall
quality scores.

Agreement is measured using:

1. **Exact agreement** — fraction of examples where the LLM and human selected
   exactly the same 1–5 overall-quality score.
2. **Cohen's kappa** — agreement beyond chance between the human and LLM labels.

The recorded evaluation produced:

- Examples compared: 50
- Human average quality: 3.44 / 5
- LLM average quality: 3.38 / 5
- Exact agreement: 94%
- Cohen's kappa: 0.887

## Judge provenance and limitation

The reply-quality LLM-judge scores were produced in the ChatGPT environment
using this rubric because no external LLM API key was available in the local
development environment.

Therefore, these scores are a recorded evaluation artifact rather than a
fully automated external API run. The agreement result should be interpreted
as supporting evidence, not as proof of production-grade evaluator reliability.

For a production evaluation pipeline, the next step would be to run the same
fixed rubric through a versioned external LLM judge and retain the raw judge
outputs alongside the human labels.
